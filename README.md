لعبة Story Tree — فولغرانيا ودنيبرالاند
الفرق عن نسخة الذكاء الاصطناعي الحية
مفيش أي استدعاء API وقت اللعب خالص. كل القصة والفروع والنهايات مكتوبة مسبقًا في ملفات JSON. ده معناه:
✅ مجانية 100% للأبد — مفيش تكلفة تشغيل بتزيد مع عدد اللاعبين
✅ مفيش حاجة لـ Backend يحمي مفتاح API — كل حاجة تشتغل مباشرة على المتصفح
✅ نتائج ثابتة ومضمونة — مفيش رد غريب أو JSON مكسور
❌ لازم تكتب كل فرع بنفسك (أو بمساعدة كلود وقت الكتابة، مش وقت اللعب)
❌ عدد الاحتمالات محدود بعدد الفروع اللي كتبتها
هيكل المشروع
Code
شكل ملف الشجرة (JSON)
كل عقدة (node) فيها:
text: النص اللي بيتعرض للاعب
choices: قايمة خيارات، كل خيار له text (نص الزرار) و next (id العقدة اللي بعده)
أو ending: لو العقدة دي نهاية، بدل choices
Json
إزاي تضيف فرع جديد
افتح ملف الدولة (data/volgrania.json أو data/dniprland.json)
ضيف عقدة جديدة بـ id فريد
اربطها من عقدة موجودة عن طريق next
لو نهاية، استخدم "ending": "اسم النهاية" بدل choices
إزاي تضيف دولة جديدة
اعمل ملف JSON جديد في data/ بنفس الشكل
في App.jsx، ضيفه لـ STORIES object وزرار اختيار جديد
الخطوة الجاية
اختبار الشجرتين الحاليتين وتوسيعهم (فروع أعمق، نهايات أكتر)
لو عايز فروع مشتركة بين الدولتين (قرار فولغرانيا يأثر على قصة دنيبرالاند) — ده محتاج تصميم إضافي، نتكلم عليه لما تجهز
